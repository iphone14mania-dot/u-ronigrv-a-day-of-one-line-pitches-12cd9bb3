A tiny Node program that writes one sentence to `/output/entry.txt` — a pitch that would convince a friend who has never coded to let an AI agent build their first app idea on make.fun. It opens on the friend's own history ("already described your app idea a hundred times") and turns it into the offer: say it once, an agent builds a first version, and you only keep going if you like what you see. 174 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
